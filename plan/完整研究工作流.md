# 完整研究工作流：从模型冻结到 LA 校准

## 0. 研究对象与不可变边界

核心对象是商业 AV operator coalition design。野火是外生网络扰动；AV 继续服务短时间窗内的已接受 pickup-dropoff 订单；订单所有权和 OD 不变；HDV 是普通、获得公开道路信息但不受直接控制的交通；监管者强制临时 operational coalition，但不逐车指定路线。本文不做 evacuee demand、rescue fleet、shelter assignment 或自愿 formation stability。

## 1. 模型与代码冻结

目标：证明当前 fixed-reference governance family 的 potential/VI 对应，固定符号、信息结构、容差、随机种子和输出 schema。

验证：Jacobian symmetry、potential gradient、OD conservation、closed-edge feasibility、VI gap、omitted-route slack、baseline JSON 不变。

产物：模型规格、假设表、potential certificate、代码版本和 regression log。

## 2. 初步实现结果

目标：用小网络验证 hazard state 不改变 coalition 定义，只改变道路状态。

实验：parallel-edge smoke、ordinary HDV、商业 AV OD、capacity loss、single closure、singleton/grand。

产物：`wildfire_snapshot_smoke_results.json`。这些结果只能证明接口可运行，不能证明 LA wildfire policy。

## 3. 场景构造验证

目标：让 synthetic hazard scenario 具备空间解释，而不是按高频 edge 任意挑边。

方法：空间 footprint、interior closure candidates、boundary degraded edges、独立 critical edges、distance/risk metadata；critical 与 degraded 尽量不重合。

验证：每个 OD 至少保留一条 route；关闭边不进入 shortest-path oracle；场景具有连续 footprint；严重程度单调改变容量或可达性。

## 4. Pilot partition audit

目标：在低计算成本下确认 hazard state 是否有可能改变 coalition ranking。

设计：20 个 OD、4 个场景、2 个 alpha、2 个 gamma、15 个 partitions；同时跑 V0 base slope 和 V2 same-hazard slope。

分析：TSTT best partition、critical v/c、AV order cost、risk diagnostic、Pareto set、grand/singleton regret。

门槛：所有 profile certified；至少记录一个 null result；不能因结果不支持 partial 而修改场景。

## 5. Full-OD no-hazard regression

目标：证明 hazard adapter 在无灾害状态下与原 Sioux Falls baseline 完全一致。

设计：528 OD、60 profiles；profile-level checkpoint、resume、warm-start、route-set reuse。

门槛：相对 TSTT 差异 <= `1e-8`；VI gap <= `1e-6`；omitted-route slack <= `1e-6`。如果运行成本过高，先做 solver profiling 和分块，不放宽精度。

## 6. Full-OD hazard audit

目标：在不改变 coalition model 的前提下测量 hazard-dependent partition regimes。

核心设计：3 类 hazard x 3 severity x alpha `{0.3,0.6,0.9}` x gamma `{0.25,0.5,0.75}` x 2 order-exposure designs = 162 states；每状态 15 partitions。

输出：outcome vector、TSTT-best、Pareto front、epsilon-selected policy、critical v/c、AV order cost、risk metric、governance burden。

## 7. Access/control and HDV de-screening

目标：检验 H-A 和 H-C，而不是只比较全网 TSTT。

设计：降低 HDV substitute-route capacity；固定 AV access restriction；比较 no restriction、soft restriction、hard closure；报告 activated-response proxy、critical v/c 和 coalition value。

## 8. Reference-slope robustness

目标：判断 partial regime 是否依赖 calibration。

比较：V0 base-network slope、V2 same-hazard HDV-only slope、no-coordination reference slope、`kappa_b` scales `{0.25,0.5,1,2,4}`、state mode diagnostic。

## 9. Information robustness

目标：把 H6 变成可检验的行为模型。

方法：将 perceived state 与 true state 分离；HDV 使用 stale public penalty/closure map，实际 TSTT 使用 true state；已关闭道路需要显式 discovery-and-reroute rule。另做 noisy regulator estimates。

## 10. Exposure-based grouping

目标：检验 H-B。

方法：保持总质量和 HHI 不变，改变公司订单对 critical edges 的暴露；比较同暴露合并、异暴露合并、无共享边合并；报告 pairwise route-incidence 和 coalition benefit。

## 11. Score-guided policy

目标：连接 activated-response theory 与计算政策。

方法：在 fixed support 上计算 merge score；对 gamma=1、near-zero score、curvature singular 或 support change 自动 fallback 到 certified finite solve。

指标：sign accuracy、ranking correlation、finite regret、equilibrium solves、runtime、fallback rate。

## 12. Scalability

目标：证明方法不是只适用于 n=4。

设计：n=6 exhaustive；n=8 selected-state/full where feasible；n>=10 beam/local/score search；报告 runtime、memory、coverage、best-known regret。

## 13. Real-world LA calibration

目标：将 synthetic hazard state 限定在现实范围内，而不是声称经验识别。

数据：OSM/Caltrans/LADOT network；PeMS traffic；CAL FIRE/NIFC/FIRMS fire perimeter；NOAA wind；QuickMap closures；LA emergency GIS critical corridors；AV service-zone or order data if available。

校准：用真实 closure/capacity ranges、路段速度和火灾推进时间校准 scenario；AV order OD 和 \(\tau_i\) 若不可得，标为 calibrated synthetic。

## 14. 证据与写作顺序

先写方法和验证，再写 pilot diagnostics，再写 full-OD hazard results；每个 claim 必须对应 raw data、summary、validator、table/figure 和 limitation。任何未运行结果只留在 protocol，不进入 Results/Discussion。
